# NEXORA-premium-login
Premium SaaS login page UI design created using Figma. 
NEXORA - Premium SaaS Login Page

Project Overview

NEXORA is a modern and premium SaaS login page UI designed using Figma.

Design Highlights

- Modern split-screen desktop layout
- Responsive mobile layout
- Navy blue and lavender colour palette
- Email and password input fields
- Password visibility toggle
- Remember Me checkbox
- Forgot Password option
- Google sign-in option
- Clean typography and user-friendly interface

Tools Used

- Figma
- UI/UX Design
